## 검증 범위와 GitHub 준비 상태

역할·파일 구조·문서 연결·JSON 문법·Git 제외/추적 가능 여부를 확인했다. 실행 코드·의존성·설치 명령·외부 API·AI 모델·음성·브라우저 인쇄는 아직 구현하지 않았으므로 실행 테스트나 실제 데이터 검증을 수행했다고 주장하지 않는다.

Git 추적 검사는 프로젝트의 임시 복사본에서 수행했으며 결과물에 .git 메타데이터를 넣지 않았다. 실제 프로젝트의 Git 초기화·커밋·원격 저장소 생성·업로드는 수행하지 않았다. ZIP을 풀면 초기 파일 구성을 GitHub에 올리기 위한 작업을 시작할 수 있다.

ZIP은 이 저장소의 파일만 포함하도록 생성한다. 압축 이후 파일 목록과 각 항목의 바이트를 원본과 비교하고, 차이가 있으면 전달을 중단한다. 참고 사진·임시 검사 파일·외부 도구 파일은 포함하지 않는다.

## 개발 기준안 v0.1 추가 후 검증 — 2026-10-25

시연 범위·기술 스택·공통 데이터·API 처리 정책을 development-plan.md에 추가하고 README·역할·API·출처·구조 문서를 함께 갱신했다. 이전 31개 파일의 ZIP은 최초 산출물이며, 현재 저장소는 문서·설정 8개와 temp 24개로 총 32개 파일이다.

- 실제 파일 트리와 structure.md의 트리가 일치한다.
- 역할은 5개, 프론트엔드는 한 앱이며 A/B의 기능 경계를 유지한다.
- 합성 정류장 5개·노선 2개·목적지 3개의 ID와 노선 순서, 병원/시장 직통 및 터미널 환승 연결이 서로 일치한다.
- 공개 API 8개와 JSON 예시 11개의 문법, expiresAt을 포함한 요청/응답 예시를 확인했다.
- 문서의 로컬 상대 링크가 실제 파일을 가리킨다.
- temp 24개의 위치·내용을 유지했고 완전히 비어 있는 폴더가 없다.
- 임시 복사본에서 Git 스테이징으로 32개 파일의 추적 가능 여부를 확인했다. 향후 SQLite 실행 파일·저널을 둘 backend/.local/과 기존 환경변수·의존성 경로가 제외된다.
- 아직 생성하지 않은 앱·API·AI·음성·인쇄 코드의 실행 테스트나 공식 교통 데이터 검증을 수행했다고 주장하지 않는다. 기술 문서 출처는 development-plan.md 9절에 기록했다.

이 검증은 문서·구조·합성 데이터 정의·Git 제외 규칙을 대상으로 한다. 실제 앱의 기능·성능·접근성 준수 완료를 뜻하지 않는다.
