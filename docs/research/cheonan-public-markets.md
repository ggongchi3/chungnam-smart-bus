## 중앙시장 중복과 주소 차이

천안중앙시장과 남산중앙시장은 별개 목적지로 등록하지 않는다. 충남 관광 공식 설명은 남산중앙시장에서 시작해 주변 시장과 통합한 현 천안중앙시장의 관계를 설명한다. 단일 고유 ID에 과거 명칭을 별칭으로 추가한다.

공식 자료에 주소가 두 종류다.

- 충남 관광의 시장 방문지 대표주소: `동남구 사직로 7`.
- 전국전통시장표준데이터: `동남구 사직2길 19 (남산중앙시장상인회)`, 지번 `사직동 263`, 좌표 `(36.80032317, 127.1484498)`.

관광 목적지에는 대표주소 `사직로 7`을 사용하는 편이 적절하다. 상인회 주소에 연결된 좌표를 대표주소의 정확한 좌표처럼 붙이지 않도록 이 기록에서는 중앙시장 좌표를 `null`로 제안한다. 두 주소를 서로 다른 시장 두 곳으로 생성하지 않는다.

## 구현 시 보존할 경계

- 고유 ID·시설명·카테고리·주소·별칭·출처 URL·조회일을 같은 장소 항목에서 관리한다.
- 기존 서버 카테고리에 관공서가 없다는 사실과 UI 분류를 구분한다. 카테고리 확장을 하더라도 DB 제약·기존 요청/응답을 깨지 않는 추가 방식으로 검토한다.
- 이 조사로 목적지 시설이 실제 존재함을 확인한 것이며, 기존 합성 노선에 이 시설을 연결할 근거는 없다. 검증되지 않은 `DestinationAccess` 또는 환승·정류장 연결을 만들지 않는다.
- 공식 찾아오시는 길에 버스 번호가 적혀 있어도 현재 출발 정류장에서의 경로 연결과 실시간 운행을 검증한 것은 아니므로 자동 경로 데이터로 복사하지 않는다.
