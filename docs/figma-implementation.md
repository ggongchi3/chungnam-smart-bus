# Figma 프론트엔드 구현 보고

작성일: 2026-11-10, Asia/Seoul. [Figma 복사본](https://www.figma.com/design/w1O09Ota2UTXzMNHNgaLlw/?node-id=27-3424)을 기존 프로젝트에 적용한 범위와 기능 연결을 기록한다. 최종 검증 결과는 작업 종료 시 갱신한다.

## 구현 범위와 보존 대상

기존 `frontend/`는 자리 표시자뿐이었으며 설치된 UI 프레임워크·라우터·컴포넌트는 없었다. 기존 [개발 기준안](development-plan.md)의 React + TypeScript + Vite, CSS Modules, Context + useReducer, fetch + AbortController를 따라 하나의 앱을 추가했다. 기존 기능별 폴더 구분과 API 계약을 활용했다.

백엔드·AI 소스, API 경로·응답 계약, SQLite 테이블·합성 원본·경로 계산·AI 검증 로직은 이번 프론트 구현의 변경 대상이 아니다. 사용자 PC의 기존 실행 DB나 공용 시나리오를 초기화하지 않는다. 새로운 외부 교통 API·인증·DB·비즈니스 로직을 추가하지 않았다. 공개 배포는 하지 않았다.

주요 추가 파일은 [프론트엔드 안내](../frontend/README.md)의 구조 표를 따른다. 화면 전환과 기능 조합은 `frontend/src/app/App.tsx`, 메모리 상태는 `state.ts`에 있다. 별도 URL 라우터나 저장된 사용자 이력을 만들지 않았다.

## 디자인 적용

Figma MCP로 화면별 레이아웃·폰트·색상·아이콘과 스크린샷을 읽었다. 시작, 목적지 선택·검색·검색 결과, 경로 선택, 상세, 인쇄 준비, 이용 마무리, 빈 결과와 유휴 경고 및 일반/고대비 변형을 기준으로 구성했다.

- 기준 캔버스: 1080×1920.
- 글꼴: Pretendard. 패키지의 로컬 글꼴 파일을 빌드에 포함한다.
- 일반 화면: 흰 배경, `#262626` 헤더, `#3586FC` → `#004FCF` 버튼 그라데이션.
- 고대비: `#262626` 배경, `#FCFF00` 강조색, 흰 보조 글자. 원본에서 흰 바탕인 경로 요약 등은 해당 구성을 유지한다.
- 원본 SVG·PNG 40개를 로컬에 보존했다. `frontend/public/assets/manifest.json`에 노드·화면 용도·원본 치수·파일 크기를 기록했다. 다운로드 URL을 런타임 이미지 주소로 사용하지 않는다. 디자인 전체 스크린샷을 화면 구현 이미지로 쓰지 않는다.

시제품에 필요한 시연 표시, 확인 불가 상태, 오류 복구, 도착 자료의 품질·시각, 긴 구간과 환승 안내를 표시한다. 이 정보가 시안보다 늘어나는 화면은 내용 스크롤을 사용한다. 화면에 맞추기 위해 실제 API 내용을 잘라내거나 사실 값을 바꾸지 않는다.

## 화면 요소와 기존 API 연결

아래 경로 앞에는 모두 `/api/v1`이 붙는다. 메서드·필드·응답은 [기존 API 계약](api-contract.md), 실제 `backend/api/routes.py`, `backend/models/schemas.py`를 기준으로 한다.

| 화면·요소 | 기존 API | 연결 동작 |
| --- | --- | --- |
| 헤더 현재 정류장 | `GET /stations/{stationId}` | 설정된 `demo-stop-001`의 서버 표시명 사용 |
| 병원·시장·터미널·역 분류, 텍스트 검색 | `GET /destinations` | `originStationId`, `query`, `category`로 등록 목적지 조회 |
| 자연어 검색 보완 | `POST /destination-interpretations` | 일반 검색 결과가 없을 때 등록 후보 조회. 후보는 사용자가 선택 |
| 목적지 결과 선택 | `POST /route-searches` | 현재 시각의 `departAt`과 등록 ID 전송. 최대 3개 서버 경로 사용 |
| 경로 카드 선택 | `GET /route-searches/{검색ID}/options/{선택ID}` | 버스·도보·환승 구간과 선택 버전 확인 |
| 도착·운행 변경·새로고침 | 상세 경로 뒤 `GET /live` | 상세와 같은 버전의 자료 조회. 활성 상세 화면에서 30초 간격 갱신 |
| 쉬운 문장과 음성 안내 텍스트 | `POST /easy-guidance` | 기대 버전을 전송하고 서버 검증 문장을 표시·읽기 |
| 인쇄 준비·인쇄 직전 재검증 | `POST /print-guides` | 같은 버전의 상세·운행·안내 스냅샷을 인쇄 문서로 렌더링 |

한글·영문·기호·쌍자음·삭제·띄어쓰기 키는 입력 상태를 변경한다. 검색 버튼 또는 입력창 Enter로 실제 API 검색을 실행한다. 고대비·이전·처음으로·계속 이용하기는 앱 상태를 변경한다. 이름순은 반환된 목록을 정렬하고 최소 환승은 서버가 반환한 경로 안에서 정렬한다. 음성 재생·중지는 `speechSynthesis`, 인쇄는 `window.print()`에 연결한다. 이 브라우저 기능에 존재하지 않는 별도 백엔드 API를 만들지 않았다.

## API 데이터와 디자인의 차이

| 디자인 요소 | 실제 데이터·기능 경계와 처리 |
| --- | --- |
| 예시 정류장·병원명·버스번호 | Figma에는 실제 지명과 가상 버스번호가 있다. 화면은 기존 합성 서버의 이름·ID·노선을 표시하며 DB를 시안 값으로 덮어쓰지 않는다. |
| 관공서 | API에 관공서 분류와 등록 목적지가 없어 버튼을 비활성화하고 준비되지 않았음을 표시한다. `other`로 임의 연결하지 않는다. |
| 역 | API의 `station` 분류를 그대로 조회한다. 기본 합성 자료에는 목적지가 없어 검색 결과 없음으로 표시한다. |
| 장소 주소·거리·지도 | 기본 서버는 주소 필드를 제공하지 않고 좌표·거리도 null이다. 임의 주소·거리·지도를 만들지 않는다. |
| 가까운순·최단 시간·최소 대기 | 필요한 좌표·시간·대기 자료가 없어 비활성화한다. 응답 null을 0분이나 최단 경로로 표현하지 않는다. |
| 여러 장소·경로 예시 | 합성 목적지는 병원·시장·터미널 3개이며 경로는 서버가 반환한 후보만 표시한다. 시안의 개수에 맞춘 임의 결과를 추가하지 않는다. |
| 도착 시각·운행 상태 | 실제 교통 제공자는 미연결이다. 합성 데이터임을 표시하고 unavailable/stale/unknown을 유지한다. 원천 갱신과 서버 수집 시각을 구분한다. |
| 인쇄 진행률·출력 완료 | 서버 API는 인쇄 데이터만 제공한다. 하드웨어 진행률·출력구 수령·출력 완료를 검증할 수 없어 임의 퍼센트나 출력 성공 문구를 표시하지 않는다. 인쇄창 종료 후 사용자가 출력 여부를 확인하고 재시도할 수 있다. |
| 유휴 경고 | 시안의 경고 화면에 맞춘 로컬 정책이다. 최초 무동작 120초 후 30초 경고를 표시한다. 이 최초 120초는 Figma가 정한 값이라고 주장하지 않으며 `config/kiosk.ts`에서 관리한다. |

로그인·즐겨찾기·저장 이력·음성 인식·녹음 업로드·QR 저장·실제 차량 위치·전체 시간표·요금·예약·결제·프린터 직접 제어는 이번에 추가하지 않았다.

## 상태·오류·인쇄·음성 규칙

공통 응답 `data/error/meta`와 `meta.dataMode`를 사용한다. API 클라이언트는 요청당 5초 제한을 두고 GET의 네트워크 실패·5xx만 1초 후 1회 재시도한다. POST와 4xx는 자동 재시도하지 않는다. 화면 이탈·새 요청·처음으로 이동 시 취소 신호로 이전 요청을 중단한다.

검색 ID·선택 ID·경로 버전을 유지하며, 상세·live·안내·인쇄에서 버전이 달라지거나 서버가 409/410을 반환하면 이전 안내·음성·인쇄 상태를 폐기하고 재검색하도록 안내한다. 서버 검색 유효기간 600초는 유휴 시간과 별개다. 새로고침하면 메모리 선택을 복원하지 않고 처음부터 선택한다.

도착 미수신을 결행으로 바꾸지 않는다. 운행 변경 조회 범위를 모르면 변경 없음으로 단정하지 않는다. 화면의 현재 시각이나 응답 생성 시각으로 원천 갱신 시각을 대체하지 않는다. 시각 표시는 `Asia/Seoul`을 사용한다.

인쇄용 DOM은 `/print-guides`의 스냅샷으로 고정하고, A4 세로·15mm 여백·16pt 본문을 기준으로 작성했다. 화면용 버튼을 제외하고 길어진 안내는 페이지로 나눈다. 종이에 변하는 도착 카운트다운을 싣지 않는다. 인쇄창 취소·종료와 실제 출력 성공은 구분한다.

음성은 제공된 한국어 음성 중 로컬 음성을 우선하며, 재생 전에 이전 발화를 취소한다. 중지·화면 이동·문서 비활성화 시 읽기를 취소한다. 지원 음성 없음·재생 실패 시 화면 안내를 유지한다. 실제 소리의 크기·발음·스피커 상태는 실행 기기에서 확인해야 한다.
